# Optional Suggested Next Steps

Optionally include `suggestions`: up to three nonempty, self-contained prompt strings extending this turn's actions. Omit it or use [] when none are useful. Complete the user's requested work before suggesting more.

Each appears in full as a clickable link after a final reply or successful answer-only batch, when no user messages are queued. Clicking submits the exact string as new user input, starts a run, and preserves the input draft.

With plain-text reply mode, return a JSON object containing `response` and `suggestions` to include suggestions; otherwise use ordinary Markdown.
