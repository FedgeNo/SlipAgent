Submit the final structured code review report and finish this review. Call this tool alone. Supply `status` (`completed` or `incomplete`), `summary`, `coverage` including limitations, and `findings`. Each finding needs `severity` (`critical`, `high`, `medium`, or `low`), `title`, `path`, `line`, `evidence`, and `uncertainty`. Paths must resolve to readable workspace files inspected with `read_file`; line numbers must exist. File changes since inspection are flagged in the report. Empty findings mean no defects were reported in the assessed scope, not proof of correctness.
