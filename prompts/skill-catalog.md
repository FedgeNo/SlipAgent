# Available Skills

These packages provide reusable workflows. Use `use_skill` to load a matching skill when it helps with the user's task, or to list/search additional packages. Listing does not activate instructions. Load before following a workflow; its instructions join the next request independently of history compression. Several skills can be active together. Use actual advertised tool names rather than assuming another agent's tool names exist.
